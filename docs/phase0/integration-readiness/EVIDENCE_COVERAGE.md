- Corrected demonstrated stale poll ordering, stale optional Pause precondition, queued-event false fault, read/write SQLite contention and repeated normalization cost remain distinct from REL-01/02. Raw failures stay preserved in M9 evidence; do not relabel failed exploratory campaigns as passes.
- Target CPU/IO/thermal/power-loss behavior, unattended availability, real sensor/camera/model performance and novice usability remain unmeasured or unaccepted. The 72-hour simulation is not a real 72-hour continuous run or the 60-/90-day grow/service-life requirements.

This gate is a proposal, not acceptance or execution authority.
